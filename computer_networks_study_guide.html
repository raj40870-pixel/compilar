Unit 1

Basic Network Concepts

Data Communication Components

Data communication is the exchange of data between two devices via some form of transmission medium. A complete data communication system is built upon five essential pillars:

  1. Message: The information (data) to be communicated. Common formats include text, numbers, pictures, audio, and video.
  2. Sender: The device that sends the data message (computer, workstation, telephone handset, video camera, etc.).
  3. Receiver: The device that receives the message (computer, workstation, television, terminal, etc.).
  4. Transmission Medium: The physical path by which a message travels from sender to receiver (twisted-pair wire, coaxial cable, fiber-optic cable, radio waves).
  5. Protocol: A set of rules that govern data communications. It represents an agreement between the communicating devices. Without a protocol, two devices may be connected but not communicating.

Network Topologies

Topology refers to the physical or logical layout in which nodes, links, and devices are arranged. Choosing a topology impacts network resilience, costs, and scalability.

Bus Topology

All nodes share a single central cable. Single point of failure; collision prone.

Star Topology

Nodes connect to a central Hub/Switch. Highly robust; easily expandable.

Ring Topology

Circular ring passing tokens. Orderly access, but a broken link halts communication.

Mesh Topology

Point-to-point links. Maximally redundant, private, and secure; complex cabling.

Unit 2

Physical Layer

Transmission Media

Transmission media is the physical path between sender and receiver. It is broadly categorized into:

Guided (Wired) Media

Signals are guided along a solid material path (cables).

  • Twisted Pair: Copper wires twisted to reduce electromagnetic interference (crosstalk). Cat6 supports up to 10 Gbps.
  • Coaxial Cable: Solid copper core shielded with braided mesh. Ideal for broadband cable feeds.
  • Fiber Optic: Glass or plastic core using Total Internal Reflection to transmit data via light pulses. Offers highest bandwidth, immune to EMI.

Unguided (Wireless) Media

Electromagnetic waves are radiated through space without physical guidepaths.

  • Radio Waves: Multidirectional, low-frequency waves capable of passing through structural walls.
  • Microwaves: Unidirectional, line-of-sight propagation. Widely used for satellite feeds and towers.
  • Infrared: Short-range, line-of-sight communication (remotes). Cannot pass through solid barriers.

Signal Impairments

Signals undergo degradation as they travel over physical media. The three main impairments are:

1. Attenuation

Loss of signal energy over distance. Signals degrade into thermal energy. Repeaters/amplifiers are installed to boost attenuation losses.

2. Distortion

A change in the shape of a composite signal made of different frequencies. Since different frequencies travel at slightly different speeds through a medium, they arrive at the destination out of phase.

3. Noise

External interference corrupting the signal. Includes Thermal Noise (random electron movement), Induced Noise (from external motors/appliances), Crosstalk (adjacent wire leakage), and Impulse Noise (spikes).

Data Rate Limitations

The maximum theoretical speed of data transmission depends on the bandwidth and noise levels:

Theorem Channel Type Mathematical Formula Key Parameters
Nyquist Bit Rate Noiseless Channel Bit Rate = 2 × Bandwidth × log₂(L) L = Number of signal levels. Maximum rate is constrained by signal levels.
Shannon Capacity Noisy Channel Capacity = Bandwidth × log₂(1 + SNR) SNR = Signal-to-Noise Ratio (Power ratio). Represents absolute speed ceiling.
Unit 3

Data Link Layer

Framing & Flow Control

The Data Link Layer structures raw bits into logical units called Frames. It regulates transmission rate to match slow receivers (Flow Control) and handles corrupt packets.

Framing Methods

To allow a receiver to identify frame boundaries, standard structures are used:

  • Character Count: Specifies the total number of characters in the frame in the header. (Risk: if count gets corrupted, all subsequent frame alignment is lost).
  • Bit Stuffing: Uses a special flag byte (e.g. 01111110) to demarcate the start and end. If the sender finds five consecutive 1s in the data, it inserts a dummy 0. The receiver filters this dummy bit out.

Flow Control Strategies

Sliding Window protocols allow sending multiple frames without waiting for immediate individual acknowledgments.

Error Handling

Error Detection: CRC

Cyclic Redundancy Check (CRC) uses polynomial division. Data bits are appended with n-1 zeros, and divided by an n-bit generator polynomial using XOR division. The resulting remainder is appended to the message. The receiver divides the message; a non-zero remainder signals corruption.

Error Correction: Hamming Code

Hamming Code inserts parity check bits at positions 2^k (1, 2, 4, 8, etc.). Each parity bit validates selected sets of data bits. If parity checks fail, adding the index weights of all failed tests pinpoints the exact bit flipped, correcting it on the fly.

Routing Algorithms

Distance Vector Routing

Uses the Bellman-Ford algorithm. Routers advertise their routing tables containing hop counts and destination keys only to adjacent direct neighbors periodically. RIP is a classic implementation. Limited by slow convergence and the "Count-to-Infinity" loop issue.

Link State Routing

Uses Dijkstra's shortest path algorithm. Routers flood link state status to the entire network, building a comprehensive local topological map of the environment. OSPF uses this, converging fast with zero loop risks.

Unit 5

Transport Layer

Transmission Control Protocol (TCP) vs. User Datagram Protocol (UDP)

The Transport Layer provides logical end-to-end communication channels between applications. The choice between TCP and UDP defines the speed and reliability characteristics of the connection:

Criteria TCP Protocol UDP Protocol
Connection State Connection-Oriented (Three-Way Handshake) Connectionless (Fire and Forget)
Reliability Guaranteed delivery. Drops trigger retransmission. Best-effort delivery. Packets can be lost.
Flow/Congestion Has sophisticated sliding-windows & rate adaptors. No rate management. Transmits as fast as possible.
Header Overhead 20 to 60 Bytes (Contains flags, options) Fixed 8 Bytes (Lightweight)
Ideal Workloads Web browsing (HTTP), Email (SMTP), File transfer (FTP). VoIP, Video Streaming, Gaming, DNS lookup.

TCP Congestion Control

TCP regulates network buffer congestion by adjusting its Congestion Window (cwnd) dynamically in response to packets dropping:

  • Slow Start: Starts with cwnd = 1. Doubles window size every Round Trip Time (RTT).
  • Congestion Avoidance: Once cwnd reaches the threshold (ssthresh), switch to linear growth (increments by 1 packet per RTT).
  • Fast Retransmit: If sender gets 3 duplicate ACKs for a frame, it assumes loss occurred and resends the segment immediately, rather than waiting for timer timeout.
Unit 6

Application Layer & Security

Application Services Overview

The top-most layer bridges network architectures to client software interfaces. It processes high-level application protocols:

DNS (Domain Name System)

Translates host domains (e.g. wikipedia.org) to logical IP locations. It is a hierarchical, distributed database queried using UDP on port 53.

HTTP vs. HTTPS

HTTP (Port 80) transmits raw text payloads. HTTPS (Port 443) wraps the connection inside encrypted TLS (Transport Layer Security) tunnels, verifying authority with SSL certificates.

Network Security Foundations

Protecting internal networks from unauthorized access involves two primary tools:

Firewalls (Security boundaries)

Analyzes packet structures to filter unwanted access. Can be Stateless packet filtering (filtering by source IP/ports) or Stateful Inspection (understanding active session context and blocking unrequested inbound packets).

VPNs (Virtual Private Networks)

Extends private networks across public paths using secure tunnel encryption. Standard tunneling frameworks include IPsec (layer 3 network encapsulation) and SSL/TLS portals (layer 4 tunnels).
